# Edukasi-TB-Berhenti-Merokok-dan-Patuh-Minum-Obat
Website inovasi PETA PARU (Program Ekonomi Token dan Adaptasi Perilaku Merokok) sebagai media edukasi dan pendampingan pasien TB paru untuk membantu mengurangi kebiasaan merokok, meningkatkan kepatuhan pengobatan, serta mencegah re-hospitalisasi melalui pelayanan berkelanjutan dari rawat inap hingga rawat jalan di RSUP Dr. Sitanala.
